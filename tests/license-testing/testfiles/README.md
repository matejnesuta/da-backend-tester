# License Sample Files

This directory contains sample license files for testing the `/licenses/identify` endpoint.

These files are used by `test_licenses.py` to verify that the backend can correctly identify licenses from their text content.

## Files

- `LICENSE-MIT` - MIT License
- `LICENSE-Apache-2.0` - Apache License 2.0
- `LICENSE-GPL-3.0` - GNU General Public License v3.0
- `LICENSE-BSD-3-Clause` - BSD 3-Clause License
- `LICENSE-LGPL-3.0` - GNU Lesser General Public License v3.0

## Usage

These files are read by the test suite and uploaded to the backend's license identification endpoint to verify proper license detection.
